# Simulation Runs: 
This folder contains the details of each simulation run for the 2026 BEAVRS benchmark in "A Systematic Re-evaluation of the BEAVRS Benchmark with OpenMC".

A full table of the details and differences between each run is in Runs.xlsx, and the code used to run each simulation, the output XML files, and a .txt file of the OpenMC output for each run can be found under /Runs. 

Note: a few runs had to be redone due to missing files so openmc_output.log might have a slightly different keff than reported in the paper, but never more 1 pcm difference.
