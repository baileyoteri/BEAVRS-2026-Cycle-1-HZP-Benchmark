This folder contains all of the XML and output logs of the runs performed for the BEAVRS 2026 benchmark. 

For runs that used OpenMC 0.9.0 or 0.10.0, a cross section library had to be manually built using 'convert_mcnp71_HDF5.py' and 'convert_Lib80_HDF5.py' as libraries properly formatted for these versions of OpenMC are no longer avalible to download. 
The runs that used this cross section library are: 003, 004, 010, and 011.
