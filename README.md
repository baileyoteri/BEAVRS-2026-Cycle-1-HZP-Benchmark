# BEAVRS PHYSOR 2026 Cycle 1 HZP Benchmark
Code and instructions to accompany the BEAVRS 2026 Benchmark publication to easily recreate results shown in paper. 

Because the BEAVRS repository gets regular updates to improve the accuracy and functionality of it (https://github.com/mit-crpg/BEAVRS), this repository has the exact model used for the 2026 HZP Cycle 1 benchmark from the paper "A Systematic Re-evaluation of the BEAVRS Benchmark with OpenMC". 

- If trying to recreate the published benchmark results exactly for replication, it is recommended  to use this version. 

- If wanting to use the most up to date version of BEAVRS, it is recommended  to use the main MIT-CRPG repository.

__This repository supports the paper presented at PHYSOR 2026. Please cite the paper if you use these materials.__

B. Oteri, B. Forget, A. Osborne, and J. Liang, “A Systematic Re-evaluation of the BEAVRS Benchmark with OpenMC,” presented at the The International Conference on Physics of Reactors, Torino, Italy, Apr. 2026.
